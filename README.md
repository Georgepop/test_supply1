Проект
>Заявки на распределение по Case
>
>мы смотрим лоты каждой заявки, то есть товары помещены в лоты (10,10,10)
>
>далее мы учитываем приоритетность
>
>товары с большим приоритетом имеют больший шанс быть отгруженными со склада
>
>Далее мы смотрим каждый Case_ID, и по  нему выставляем товары каждой заявке.

Технологии ortools, numpy
